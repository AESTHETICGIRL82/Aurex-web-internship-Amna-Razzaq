## Week 2 — CSS3 + Modern Layouts (Flexbox & Grid) + Responsive Design

| Section | Details |
|---|---|
| **Task** | Transformed the Week 1 HTML profile into a fully styled, responsive personal portfolio using modern CSS3. |
| **Live Deployment Link** | [https://aestheticgirl82.github.io/Aurex-web-internship-Amna-Razzaq/](https://aestheticgirl82.github.io/Aurex-web-internship-Amna-Razzaq/) |
| **Tech Used** | HTML5, CSS3, Git, GitHub, GitHub Pages |
| **CSS Features & Layout Techniques** | **Flexbox** — used for header layout, navigation alignment, and mobile menu structure. **CSS Grid** — used for the main content layout and skills list. **Media Queries** — two breakpoints (900px for tablet, 600px for mobile) for a fully responsive, mobile-first navigation menu. Also used CSS variables (`:root`), smooth transitions, sticky header, and hover effects for better UI/UX. |
| **Key Learnings** | Learned how Flexbox and Grid work together for structuring a page, how to build a mobile-first responsive design using media queries, and how to deploy a static site live using GitHub Pages. |
| **Challenges / Blockers** | Making the hamburger menu smoothly transition between desktop and mobile views took some trial and error, especially handling the `nav` visibility and animation states across breakpoints. |
